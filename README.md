# تحويل نطاق منيو سويق القديم

هذا الفرع يحول `menu.saweegsa.com` إلى المنيو الموحد داخل:

- العربية: `https://go.saweegsa.com/menu/`
- الإنجليزية: `https://go.saweegsa.com/menu/en/`

تطبيق المنيو وبياناته وصوره انتقلت إلى مستودع `saweeg-home`، وهو مصدر الحقيقة الوحيد لأي تعديل جديد. يحتفظ هذا الفرع مؤقتًا بملفات التطبيق القديمة كنسخة رجوع وفق خطة الانتقال، لكن مسار النشر لا يبنيها ولا ينشرها؛ إذ ينشر فقط صفحة تحويل تحفظ اللغة، جميع معاملات الرابط، والجزء الذي يبدأ بـ`#` عند توفر JavaScript.

## الاختبار

```bash
node --test tests/redirect.test.mjs
```

## النشر

ينشر GitHub Actions محتويات `site/` فقط عند الدمج إلى `main`. هذا تحويل HTML/JavaScript باستخدام `location.replace`، وليس HTTP 301. وسم `meta refresh` احتياطي عند تعطيل JavaScript، لكنه لا يستطيع حفظ معاملات الرابط أو الجزء `#`.

يبقى `site/CNAME` على `menu.saweegsa.com`. لا تغير DNS أو Pages قبل نجاح نشر المنيو الموحد والتحقق منه.

لا تُحذف ملفات التطبيق القديمة ولا يُؤرشف هذا المستودع إلا بعد اعتماد الانتقال صراحةً.
